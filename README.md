# SAGA

Singapore Armed Forces Growth Archive.

This is a Vite + Vue 3 Composition API + Vue Router demo built as a military scrapbook for Singapore NSmen.

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Pages

- `/` dashboard dossier
- `/timeline` NS memory timeline
- `/yearbook` cohort yearbook
- `/letters` sealed letters system
- `/achievements` medal shelf
- `/ord-reel` ORD reel preview
